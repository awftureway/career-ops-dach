career-ops-dach mit Claude Code einrichten

Diese Anleitung führt Sie in neun Schritten von einem leeren Rechner zur ersten bewerteten Stellenanzeige. Rechnen Sie mit etwa 30 Minuten, den größten Teil davon für Ihr Profil.

Bevor Sie beginnen: Ihre Daten bleiben lokal.

Alles, was Sie über sich eingeben (cv.md, config/profile.yml, portals.yml, modes/_profile.md, der Ordner data/ mit dem Tracker, reports/ und output/), bleibt als Datei auf Ihrem Rechner. Diese Dateien sind per .gitignore von Git ausgeschlossen. Zur Bewertung schickt Claude Code die benötigten Inhalte an Anthropic; mehr dazu in PRIVACY.md.

  1. Voraussetzungen prüfen

    Sie benötigen:

    • Node.js 22.13 oder neuer (ab Version 23 mindestens 23.4). Download unter nodejs.org. npx ist darin enthalten.
    • Git, um das Repository herunterzuladen.
    • Claude Code mit einem Claude-Abonnement oder einem API-Zugang (siehe Schritt 4).

    Prüfen Sie im Terminal, welche Versionen installiert sind:

    node --version
git --version

    Unter Windows beachten Sie bitte die Hinweise in WINDOWS.md.

  2. Repository klonen

    Laden Sie career-ops-dach in einen Ordner Ihrer Wahl und wechseln Sie hinein:

    git clone https://github.com/awftureway/career-ops-dach.git
cd career-ops-dach
    Hinweis zum Installer

    Der Befehl npx @santifer/career-ops init aus dem Originalprojekt installiert das ursprüngliche career-ops ohne die DACH-Erweiterungen. Für diese Version verwenden Sie bitte git clone wie oben.

  3. Abhängigkeiten installieren

    npm install

    Dabei wird auch der Browser Chromium für Playwright heruntergeladen. Er wird für PDFs und für die Prüfung, ob eine Stelle noch ausgeschrieben ist, gebraucht. Falls dieser Teil fehlschlägt, holen Sie ihn so nach:

    npx playwright install chromium

  4. Claude Code installieren und starten

    Installieren Sie Claude Code nach der offiziellen Anleitung auf claude.ai/code. Starten Sie es anschließend im Projektordner:

    claude

    Beim ersten Start melden Sie sich mit /login an. Claude Code liest dann automatisch die Projektregeln aus CLAUDE.md und AGENTS.md, und der Befehl /career-ops steht zur Verfügung. Ohne Zusatz zeigt er das Befehlsmenü.

    Abonnement oder API-Schlüssel?

    Ist in Ihrer Umgebung die Variable ANTHROPIC_API_KEY gesetzt, verwendet Claude Code diesen Schlüssel und rechnet pro Token ab, auch wenn Sie ein Abonnement haben. Prüfen Sie das mit echo $ANTHROPIC_API_KEY. Gibt der Befehl etwas aus und möchten Sie Ihr Abonnement nutzen, entfernen Sie die Variable aus Ihrem Shell-Profil, starten das Terminal neu und melden sich mit /login an.

  5. Systemcheck ausführen

    Der Systemcheck zeigt, ob alles bereit ist und welche persönlichen Dateien noch fehlen. Sie können ihn in einem zweiten Terminal im Projektordner selbst ausführen; Claude Code ruft ihn vor der ersten Bewertung ohnehin auf.

    node doctor.mjs --json

    Die wichtigsten Felder der Ausgabe:

    FeldBedeutung
    onboardingNeededtrue, solange Pflichtdateien fehlen. Dann folgt die Einrichtung in Schritt 6.
    missingWelche von cv.md, config/profile.yml, modes/_profile.md und portals.yml noch fehlen.
    unpersonalizedDateien, die noch Vorlageninhalt enthalten. Ein unverändertes modes/_profile.md bewertet Stellen nach dem Profil des Vorlagenautors, nicht nach Ihrem.
    warningsHinweise, die die Nutzung nicht blockieren.

    Eine gut lesbare Fassung für Menschen erhalten Sie mit npm run doctor. Der Befehl ist rein lesend und legt keine Dateien an.

  6. Einrichtung im Gespräch

    Sie müssen keine Konfigurationsdatei von Hand bearbeiten. Schreiben Sie in Claude Code zum Beispiel:

    Richte bitte mein career-ops-Profil ein.

    Claude Code führt Sie dann durch diese Schritte und fragt Sie vor jedem Schritt nach Ihren Angaben:

    1. Vorlagen anlegen mit node doctor.mjs --json --init-templates. Fehlende Dateien wie modes/_profile.md werden aus Vorlagen kopiert, bestehende bleiben unverändert.
    2. Lebenslauf (cv.md): Sie fügen Ihren Lebenslauf als Text ein oder beschreiben Ihre Erfahrung. Daraus entsteht eine Markdown-Datei mit Abschnitten wie ## Experience und ## Skills. Die Struktur zeigt examples/cv-example.md.
    3. Profil (config/profile.yml): Name, E-Mail, Wohnort und Zeitzone, Zielpositionen, Gehaltsvorstellung mit Währung und die gewünschte Kostenstufe (economy, standard oder premium).
    4. Portale (portals.yml): Suchbegriffe für Stellentitel, ausgeschlossene Titel und erlaubte Länder oder Städte. Claude Code schreibt Profil und Portale gemeinsam mit node onboard-write.mjs.
    5. Tracker: Fehlt data/applications.md, wird eine leere Tabelle angelegt.
    6. Werkzeug merken mit node remember-cli.mjs claude, damit Skripte und Weboberfläche wissen, dass Sie Claude Code verwenden.

    Zum Schluss erzählen Sie mehr über Ihre Stärken, Ausschlusskriterien und Erfolge. Diese Angaben landen in config/profile.yml, modes/_profile.md oder article-digest.md und verbessern jede spätere Bewertung.

    Ausgabe auf Deutsch

    Damit Berichte, Notizen und Anschreiben auf Deutsch erscheinen und der deutsche Arbeitsmarkt berücksichtigt wird (etwa das 13. Monatsgehalt), ergänzen Sie in config/profile.yml:

    language:
  output: de
  modes_dir: modes/de

    Prüfen Sie danach erneut mit node doctor.mjs --json. Wenn onboardingNeeded auf false steht und unpersonalized leer ist, ist die Einrichtung abgeschlossen.

  7. Erster Scan

    Lassen Sie die Portale aus Ihrer portals.yml nach neuen Stellen durchsuchen:

    /career-ops scan

    Neue Treffer landen im Posteingang data/pipeline.md. Den Scanner selbst können Sie auch ohne KI im Terminal starten; das kostet keine Tokens:

    npm run scan

    Gefällt ein Scan-Ergebnis nicht, prüfen Sie die Konfiguration mit npm run validate:portals. Alle gesammelten URLs bewerten Sie anschließend in einem Durchgang mit /career-ops pipeline.

  8. Erste Bewertung

    Fügen Sie eine Stellen-URL oder den vollständigen Text einer Stellenanzeige direkt in Claude Code ein, zum Beispiel:

    https://firma.example/karriere/stellen/12345

    career-ops-dach prüft dann automatisch:

    • ob die Stelle noch ausgeschrieben ist (nur bei URLs),
    • wie gut sie zu Ihrem Lebenslauf passt, mit Bewertung von 1 bis 5,
    • und schreibt einen Bericht nach reports/, einen zugeschnittenen Lebenslauf (standardmäßig als PDF) nach output/ sowie einen Eintrag in den Tracker.

    Nur bewerten, ohne PDF: /career-ops oferta. Bei einer Bewertung unter 4,0 von 5 rät career-ops-dach ausdrücklich von einer Bewerbung ab.

    Nichts wird ohne Ihre Prüfung abgeschickt.

    Auch beim Ausfüllen von Bewerbungsformularen (/career-ops apply) hält career-ops-dach immer vor „Absenden“ an. Lesen Sie jeden erzeugten Lebenslauf vor dem Versand: Fakten werden aus Ihren Dateien übernommen und nie erfunden, die Verantwortung für das Dokument liegt dennoch bei Ihnen.

  9. Bewerbungen im Tracker verfolgen

    Alle Bewertungen stehen in data/applications.md. Eine Übersicht erhalten Sie mit:

    /career-ops tracker

    Haben Sie sich beworben, sagen Sie es Claude Code einfach („Ich habe mich auf Bericht 001 beworben“) oder setzen den Status selbst:

    node set-status.mjs --report 001 Applied

    Gültige Status sind Evaluated, Speculative, Applied, Responded, Assessment, Interview, Offer, Hired, Rejected, Discarded und SKIP. Bearbeiten Sie die Tabelle möglichst nicht von Hand. Die Konsistenz prüfen Sie mit:

    node verify-pipeline.mjs
